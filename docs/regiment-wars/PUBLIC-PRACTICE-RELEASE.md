# Regiment Wars public practice release

River authorized publishing all completed Coldstream work on 20 September 2026, with a visible Work in progress label on Regiment Wars. This supersedes the earlier no-publish restriction for the completed practice game. It does not turn browser-local records into authoritative account data.

The release includes all completed solo game work from `codex/regiment-wars` at `ab8c3b3`: 30 cards, three AI opponents, three editable decks, the full 15-slot board, an expandable collection tray, starter and sample-currency packs, crafting, saved battles, receipts, pack animation and synthesized sound.

The page displays Work in progress on every tab and explains that it uses sample Shillings, stores progress on this device, and never reads or charges the real purse. Its How to play page also explains that the save is shared by anyone using the same browser. Real accounts, real-currency packs, server-verified battles and player-versus-player still require the service described in `LAUNCH-INTEGRATION.md`.

Only the public practice route and links may be enabled. Keep the existing browser save key to preserve playtest progress. Do not connect the card store to the Quartermaster wallet, grant rewards, change profiles, or run account migrations as part of this release.

`START-HERE.md` and `REPORT-BACK.md` preserve the original local playtest history. Their earlier publication restrictions describe that earlier task. This release note is the current publication scope. Root release verification records the final deployed revision and live checks.
