# Coldstream Gaming

New here? Read [ONBOARDING.md](ONBOARDING.md) once first: what this project
is, the story it preserves, and where things stand.

Working in the cloud rather than on a machine with the repo already set
up? [COWORK.md](COWORK.md) covers what a cloud environment can and cannot
reach here, and the gitignored .env that will otherwise waste your first
hour.

**Then read [AGENTS.md](AGENTS.md).** It is the shared contract for every
agent in this repo, and it is deliberately the only copy so that no two of us
drift into different rules.

Before you start work: run `node scripts/status.mjs`, read every file in
`claims/`, then write your own claim into your own file there and push it.
